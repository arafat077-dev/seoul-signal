# Optional on-device evidence selector for Seoul Signal

The always-available analytic guide does not need a language model. The optional component uses a compact public instruct model to interpret a visitor's wording and select *existing, locally computed evidence*. Historic totals, percentages, the selection rule, affordability calculations, and the final text remain in the deterministic application. There is no hosted inference API, account, API key or per-message fee. Visitors who opt in use their own device, network and browser storage.

## Integration

Place `model.js`, `model-worker.mjs`, and the `vendor/` folder under a shared directory in the static site. Use a classic external script tag with `src` for `model.js`; do not inline it. Do not preload or service-worker precache the optional runner. Do not include the `verification/` folder in a deployment. The Apache 2.0 notices in `vendor/` accompany the optional model and runtime.

- `SeoulLocalAI.canUse(): boolean` checks secure HTTP(S), workers and browser WebGPU. The actual GPU adapter, shader-f16, memory and storage are checked when the visitor opts in.
- `SeoulLocalAI.info`: model name and ID, runtime pin, approximate model-repository and graphics-memory sizes, license, and source link.
- `await SeoulLocalAI.load(({progress, text}) => …)`: starts a dedicated worker after the visitor explicitly requests the download. `progress` is a fraction from 0 to 1; use `textContent` for labels. A missing GPU or inability to load public assets raises a human-readable error; keep all ordinary guide features usable.
- `await SeoulLocalAI.explain({question, history?, facts})`: recent history entries are `{role:'user'|'assistant', content:'…'}`; facts are `{id:'stable-id', label:'topic', text:'verified short excerpt'}`. Include existing evidence relevant to the current categories and district preferences. Maximum twelve candidate facts, of which up to three may be selected. It returns only `{ids, frame}` with `frame` one of `recommend`, `compare`, `explain`, or `limits`. Use IDs to look up the same trusted evidence and its provenance—never calculate or render a model-generated fact. Empty IDs mean insufficient evidence; use the ordinary guide or ask the visitor to narrow the question. This small model may select imperfect evidence.
- `await SeoulLocalAI.unload()` releases the running worker and GPU resources. Previously downloaded public model files can remain in the browser's site cache; visitors can remove them via the browser's site-data controls. No questions, plans or model outputs are persisted by this adapter. Loading queries only public asset URLs; visitor messages do not leave the browser.

For example, an inexpensive-accessories shopowner asking about downside risk can be routed toward seasonality, basket size and site costs instead of seeing the largest historic district automatically. A question about a retailer's actual rent receives the site-cost/limits card; the dataset contains no rent observations.

The [upstream binary at an immutable commit](https://raw.githubusercontent.com/mlc-ai/binary-mlc-llm-libs/025bcaf3780fa8254f5e5efd3bfea0a5397248f4/web-llm-models/v0_2_84/base/Qwen2-0.5B-Instruct-q4f16_1_cs1k-webgpu.wasm) is 4,850,160 bytes; its SHA-256 is verified in the browser by the inference runner, as is the model configuration. The kernel is downloaded directly from its publisher on opt-in rather than redistributed.
- **External network permissions for opt-in only:** allow the official Hugging Face model URL and the redirect/CDN targets returned for public file downloads, the pinned `raw.githubusercontent.com` kernel URL, same-origin module workers, and WebAssembly compilation. The dashboard and ordinary guide have no dependency on these hosts or capabilities.

## Verification and limits

Run `node model-tests.mjs` beside these files. Tests cover zero requests/worker construction before opt-in, capability fallback, progress, concurrent loads, cancellation, malformed or fabricated responses, allowlisted-only evidence, prior-turn handling, the integrity of the exact bundled runtime, and the version's actual model registry object. The vendor module, pinned public config, tokenizer, tensor manifest and WebAssembly binary were independently fetched and checked. The compiler kernel was also parsed as WebAssembly. **End-to-end model inference was not run on a physical WebGPU device in the build environment.** Rehearse the optional feature on the presentation laptop over Wi-Fi once before class. The default data guide requires neither the model nor a network connection to interpret its supported questions.
